# ThoTools

Free online text tools for everyday tasks.

## Available Tools

- Word & Character Counter
- Text Cleaner
- Case Converter
- Lorem Ipsum Generator
- Text Reverser
- Slug Generator
- JSON Formatter

## Live Website

https://plontotitid-jpg.github.io/ThoTools/

## Features

- Free to use
- No account required
- Works directly in your browser
- Simple and lightweight
- Mobile friendly

## Privacy

ThoTools processes text directly in the browser. No account or file upload is required.
